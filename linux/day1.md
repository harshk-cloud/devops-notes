# Day 1 - Linux Basics 

## pwd 

Meaning: print Working Directory 

Purpose: Displays the current directory (location) where I am working

Example:
pwd

Output:
/home/harshkumar 

## ls 

Meaning: List 

Purpose: Displays the files and directories in the current location.

Example:
ls

---

## cd 

Meaning: Change Directory

Purpose: 
Used to move from one directory to another.


Examples:
cd linux
cd ..
cd ~

---

## mkdir

Meaning: Make directory 

Purpose: Creates a new directory (folder).

Example:
mkdir Linux

___

## touch 

Purpose: Creates a new empty file.

Example:
touch day1.md
